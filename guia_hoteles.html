Gestión de Hoteles NUEVO

Sistema de administración de hoteles para paquetes turísticos

Paso 1: Accede a la Gestión de Hoteles

Hay dos formas de agregar hoteles:

  • Directamente desde el panel: Transporte → Hoteles
  • URL directa:
http://localhost/metelebrasil_dev/admin/hotelLista.php
Ir a Hoteles

Paso 2: Crear un Nuevo Hotel

En la lista de hoteles, haz clic en el botón "+ Nuevo Hotel"

Se abrirá un formulario donde debes completar:

  • Nombre del Hotel - Nombre completo
  • Dirección - Calle y número
  • Ciudad - Dónde está ubicado
  • Provincia/Estado - Provincia o estado
  • País - País donde está
  • Teléfono (opcional) - Para contacto
  • Email (opcional) - Para contacto
  • Descripción (opcional) - Servicios y comodidades
Crear Hotel Ahora

Paso 3: Guardar el Hotel

Una vez completados los datos básicos, haz clic en "Crear Hotel"

El sistema automáticamente:

  • Asigna el tipo "hotel" al registro
  • Obtiene las coordenadas GPS (si no las ingresas)
  • Lo marca como "Habilitado" por defecto
  • Lo guarda en la base de datos

Paso 4: Usar Hoteles en Paquetes Turísticos

Una vez creados, los hoteles se pueden usar en:

  • Rutas de transporte (como parada intermedia)
  • Paquetes turísticos (como alojamiento)
  • Tours con hospedaje
  • Excursiones de varios días

Para usar un hotel en una ruta:

Transporte → Rutas → Editar Ruta → Paradas → Agregar Parada
(El hotel aparecerá en la lista agrupado por tipo)

Información Importante

  • Los hoteles se almacenan como "paradas" de tipo "hotel"
  • Puedes editar un hotel: Hoteles → Editar (lápiz)
  • Puedes eliminar un hotel: Hoteles → Eliminar (basura)
  • Los hoteles pueden estar activos o inactivos
  • Las coordenadas se geocodifican automáticamente si las dejas vacías
